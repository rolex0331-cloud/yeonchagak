### 단위 테스트가 확인하는 것
- 2027 추석: 연차 2일(9/13, 9/17) → 9/11~9/19 9일, 1일(9/13) → 6일
- 예산 초과 없음, 연휴 간 근무일 1일 이상 간격, 연차일은 연휴 안의 평일 (예산 0~40 × 최소 길이 5종 조합)
- 동적 계획법 결과 = 완전 탐색 최적값 (두 목표 모두)
- 합계 목표에서 예산 증가 시 쉬는 날 비감소
- 5인 미만(공휴일 미적용), 대체공휴일·노동절 개별 해제, 연차 불가 기간, 확정 연차 차감·초과 오류, 회사 휴무일 반영
- 잘못된 입력 11종 거부, 경계값(연차 0일, 하루 기간, 연도 경계)
- .ics 형식(종일, DTEND 다음날, CRLF), 연차 신청 문구, 공유 링크 왕복·쓰레기 값 무시
- 여행 링크 날짜, 제휴 미설정 시 파라미터 없음 / 설정 시 부착
- 공휴일 데이터 형식·정렬·중복, 2027년 24일·대체 7일, 대체공휴일은 평일
- 모든 HTML 메타, 내부 링크 실재, sitemap URL 실재, 비밀값 패턴 없음, 앱 페이지 외부 스크립트 없음

### E2E가 확인하는 것
- 첫 방문 자동 계산, 콘솔 오류 0, 외부 요청 0
- 연차 2일 입력 → 9일 연휴 카드, 항공권 링크 날짜, 목적지 변경 시 링크 갱신·숙소 버튼 숨김, 새로고침 후 상태 유지
- 빈 입력·41일 이상 오류 표시와 결과 숨김, 0일 안내
- 공휴일 미적용 시 대체공휴일 체크 비활성, '연차 없이 쉬는 연휴 없음'
- 연차 불가 기간 추가·삭제
- .ics 파일 실제 다운로드 및 내용
- 복사 버튼: 성공 또는 실패 메시지 (가짜 성공 없음)
- localStorage 차단 환경에서 정상 동작
- 모바일 375px: 가로 스크롤 없음(4개 페이지), 버튼 높이 44px 이상
- 콘텐츠 페이지 200, 없는 주소 404 + 안내 페이지
- 제휴·측정 설정 주입 시: 고지 표시, 링크 파라미터·rel=sponsored, 이벤트 전송, 이벤트에 날짜·입력값 없음
