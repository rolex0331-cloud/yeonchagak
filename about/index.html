연차각 소개

연차각은 남은 연차를 공휴일·주말 사이 어디에 넣어야 가장 길게 쉴 수 있는지 계산하는 무료 웹 도구입니다.

계산 방법

  • 선택한 기간의 날짜를 근무일·주말·공휴일·회사 휴무일로 나눕니다.
  • 연차로 근무일을 메웠을 때 앞뒤가 근무일로 막히는 '최대 연속 휴일' 후보를 모두 찾습니다 (최대 21일 길이).
  • 추천 플랜: 보유 연차 안에서 서로 겹치지 않는 연휴들을 골라 쉬는 날 합계가 가장 많아지도록 동적 계획법으로 계산합니다. 합계가 같으면 연차를 덜 쓰는 조합을 고릅니다.
  • 연차 효율 TOP: 연휴 길이 ÷ 사용 연차가 큰 순서입니다.
  • 반차·시차 출퇴근, 교대 근무 일정은 아직 반영하지 않습니다.

공휴일 데이터

우주항공청이 매년 발표하는 월력요항(언론 보도)과 공개 공휴일 캘린더를 교차 확인해 수록합니다. 현재 확인일: 2026-10-14, 수록 연도: 2026, 2027년. 매주 자동 점검으로 공개 캘린더와 차이가 생기면 운영자에게 알림이 가고, 확인 후 반영합니다.

개인정보 안내

  • 회원가입이 없고, 입력한 연차 일수·날짜는 서버로 전송되지 않습니다. 계산은 모두 사용 중인 브라우저 안에서 이뤄집니다.
  • 다음 방문 때 편하도록 마지막 설정을 이 브라우저의 로컬 저장소(localStorage)에만 저장합니다. 브라우저의 사이트 데이터 삭제로 지울 수 있습니다.
  • '결과 공유'를 누르면 설정값(연도, 연차 일수, 선택한 날짜)이 링크 주소에 담깁니다. 이름·연락처 같은 개인 정보는 담기지 않습니다.
  • 방문 통계 도구를 쓰게 되면, 쿠키 없이 페이지 조회와 버튼 사용 횟수만 집계하는 방식으로 이 안내를 먼저 갱신합니다. 현재는 통계 도구를 사용하지 않습니다.
  • 사이트는 GitHub Pages에서 호스팅되며, GitHub는 보안 목적으로 접속 IP를 기록할 수 있습니다 (GitHub 개인정보처리방침).

여행 링크와 제휴 고지

연휴 카드의 항공권·숙소 버튼은 해당 날짜가 입력된 트립닷컴 검색 결과로 연결됩니다. 제휴 프로그램에 승인되면 이 링크는 제휴 링크가 되며, 그때부터 모든 페이지 하단에 제휴 사실을 표시합니다. 이용자가 내는 가격은 같습니다. 현재는 제휴 링크가 아닌 일반 검색 링크입니다.
